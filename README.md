# 👋 Юлия | Начинающий инженер по тестированию

Привет! Меня зовут **Юлия**. Я начинающий инженер по тестированию с **6 месяцами проектного опыта** тестирования веб-приложений и их адаптивных версий. Основной фокус — **ручное функциональное тестирование, тест-дизайн, тестирование REST API, тестовая документация и локализация дефектов**.

В проектах провожу **функциональное, дымовое, регрессионное, исследовательское, кроссбраузерное и UI/UX-тестирование**, а также повторную проверку исправленных дефектов. Знаю и применяю техники тест-дизайна: **классы эквивалентности, анализ граничных значений и переходы состояний**. Проектирую позитивные и негативные проверки, составляю чек-листы и тест-кейсы, оформляю баг-репорты. В проекте **[А-Чат](https://github.com/YULLEN1/Project-A-chat)** разработала интеллект-карту и чек-лист из **600+ проверок**, выделяла ключевые пользовательские сценарии и формировала наборы проверок для дымового и регрессионного тестирования.

Работаю с **Chrome DevTools, Postman, Swagger, JSON, SQL, DBeaver, Figma, Git и GitHub**. Проверяю REST API, анализирую сетевые запросы и ответы, работаю с консолью браузера и использую инструменты разработчика для локализации дефектов.

🎓 Получила профессиональное образование по программе **«Инженер по тестированию» в Нетологии**. Сейчас развиваю навыки автоматизации тестирования на **JavaScript + Playwright**, углубляю знания REST API и SQL. Моя цель — развиваться как инженер по тестированию, сочетая сильную базу ручного тестирования с автоматизацией.
